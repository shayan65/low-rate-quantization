# Archived experiments

Scripts from lines of work the paper does not rest on: the quantum-inspired
polar (magnitude/phase) weight code that produced the project's first negative
result, the early screens and gates that preceded the measured-storage recipe,
and superseded versions of runners that were later replaced.

They are kept because the paper reports negative results and withdrawn claims,
and a reader who wants to check one should be able to find the code that
produced it. They are **not** maintained: several import modules that now live
one directory up, so they will not run from here without adjusting the path.

Nothing in the paper's table or figure pipeline reads from this directory.
